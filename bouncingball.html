Pygame Physics Simulation

Python · Simulation · Object Oriented Programming

Recently, videos of balls bouncing around on the screen have been popular on social media. Typically, the balls will do something along the lines of growing or duplicating. The simulations are interesting to me, so I decided to try to make one myself.

Discussion

This code base sets up a simulation where balls bounce around a window. Before the main loop, a list of ball objects is created. The balls position is dependent on row and column constants and the speed and color is random.

Inside the main loop, the simulation is conducted in real time. If a ball hits the edge of the window, it bounces back. If a ball hits another ball, they bounce off each other. Each ball is checked against the other balls for a collision and their velocities are updated accordingly. Once that happens, the balls can be drawn and moved.

Collision is calculated with the normal vector and relative speed between two balls. The new speed is calculated with the current speed vectors and the projection of the relative speed onto the normal vector.

Each ball was organized with a Ball class. The class has methods for drawing and moving the ball, as well as attributes such as color, initial position, velocity, etc. The module also contains funcitons for checking and handling collisions. In addition, I also made classes to organize data for the simulation boundary, position, velocity and color. This made development easier and the code reads more like english. I also made a static method for Position, Velocity, and Color to generate random values for the balls.

Future Work

Currently, the simulation does not account for the mass of the ball, as all of the radii are equal to each other. The simulation also begins to lag if the amount of balls is very high. I'd like to further define the physics model, as well as optimize the logic for detecting collisions. The program doesn't need to check collisions with every ball, just the near by ones.
